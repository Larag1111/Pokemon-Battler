# Pokedex

A console-based Pokedex application built in Java.

## Features

- Show all Pokemon
- Add, edit and delete Pokemon
- Add and remove attacks
- Save and load Pokedex data
- Reset the Pokedex to the default Pokemon

## How to run

Open the project in IntelliJ IDEA and run `Main.java`.

The project uses Java 21 and Maven.

## Example usage

When the program starts, choose an option from the menu:

1. Show all Pokemon
2. Add Pokemon
3. Edit Pokemon
4. Delete Pokemon
5. Save
6. Load
7. Reset
8. Exit

For example, choose `1` to show all Pokemon in the Pokedex.
